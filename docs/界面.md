## 1. 设计目标

- **简洁高效**：核心功能一目了然，减少用户学习成本
- **双模式切换**：支持 LandingPage 全屏模式和侧栏编辑模式
- **实时反馈**：操作响应及时，状态变化清晰可见
- **可扩展性**：布局预留后续功能扩展空间

## 3. 各区域详细设计

### 3.1 LandingPage（全屏初始页）

通过左上角 [≡] 按钮切换显示/隐藏左侧面板。

| 区域 | 元素 | 说明 |
| :--- | :--- | :--- |
| 顶部栏 (40px) | [≡] 展开按钮 / [⊟] 最小化按钮 | ⊟点击切换窗口至投屏尺寸 |
| 内容区 | 80×80 手机图标 + 连接设备按钮 + 说明文字 | 引导用户连接设备 |
| 加载动效 | 双环旋转动画 + 三圆点弹跳 + "正在连接设备..." | 连接中/投屏加载中显示 |
| 过渡效果 | 连接成功后3秒渐出过渡 → 露出底层投屏画面 | opacity过渡 700ms ease-in-out |

### 3.2 第1栏 - ScriptPanel（脚本管理栏）

**固定宽度**：240px

| 区域 | 组件 | 说明 |
| :--- | :--- | :--- |
| 新建按钮 | outline Button | `+ 新建脚本/目录` → NewScriptDialog |
| 脚本列表 | ScrollArea | 文件夹树 + Card 脚本项 |
| 文件夹 | ChevronDown/Right + FolderOpen/Closed + 名称 + Badge计数 | 点击展开/收起 |
| 脚本项 | Card + FileCode图标 + 名称 + [🗑]（选中显示） | 选中高亮 |
| 底部 | 导入 / 导出 / 版本号（package.json读取） / [⚙] | 设置 → SettingsDialog |
| 空状态 | FileCode大图标 + "暂无脚本/目录" + 提示文字 | 无脚本时显示 |

**交互**：
- 点击文件夹 → 展开/收起子脚本
- 点击脚本 → 选中高亮，StepPanel 刷新
- 选中脚本后点击 [🗑] → ConfirmDialog 确认删除
- 点击新建 → NewScriptDialog（Tab切换：脚本/目录）

### 3.3 第2栏 - StepPanel（步骤栏）

**固定宽度**：340px

| 区域 | 组件 | 说明 |
| :--- | :--- | :--- |
| 顶部工具栏 | FileCode图标 + 名称(max 140px截断) + N步Badge / ▶运行 ⬜停止 ✏编辑脚本名 | 40px |
| 添加步骤 | outline Button | `+ 添加步骤` → NewStepDialog |
| 步骤列表 | ScrollArea | 序号 + 类型图标 + 名称 + 参数描述 |
| 操作行 | 选中步骤后显示 "[更多▼]" (编辑/删除) + "[▶]" (单步运行) | 展开式操作 |
| 底部状态 | ● Step N/M / 运行中·停止 | 进度 + 执行状态 |
| 空状态 | MousePointerClick小图标 + "该脚本暂无步骤" | 无步骤时显示 |

**步骤类型图标与中文标签**：

| 类型 | 中文标签 | 图标组件 | 参数示例 |
| :--- | :--- | :--- | :--- |
| click | 点击 | MousePointerClick | (320, 580) |
| type | 输入 | Keyboard | "admin_user_01" |
| swipe | 滑动 | ArrowUpDown | Up (1.2s) |
| longpress | 长按 | Pointer | (320, 580) 1.0s |
| home | 回主屏幕 | Home | — |
| openApp | 打开App | Puzzle | 微信 |
| ai | AI | Sparkles | "打开微信点击发送" |
| checkText | 文本检测 | ScanSearch | "成功" |
| visionClick | 识别点击 | ScanEye | "钱包" |
| wait | 等待 | Hourglass | 3.0s |

**执行高亮**：当前执行步骤显示黄色背景 (`bg-yellow-500/20`) + 左边框 (`border-l-2 border-yellow-500`)

### 3.4 第3栏 - MirrorPanel（投屏区域）

**宽度**：自适应（flex-1）

**顶部工具栏**（40px）：
- [◀] 收起侧边栏 → 返回 LandingPage
- [⊟] 最小化投屏 → 窗口缩至328px宽
- USB / Wi-Fi 连接方式标识 + 1920×1080分辨率显示
- 连接 / 断开 / 返回(←) / 首页(⌂)按钮
- X: 320 Y: 580（鼠标坐标）
- Badge "未连接"（断开时显示）

**内容区**：
- 底层：ScreenCanvas（连接后显示TinyH264解码的实时投屏画面）
- 顶层遮盖层：
  - 未连接：80×80 手机图标 + 连接设备按钮 + 说明文字
  - 连接中：旋转动画 + "正在连接设备..."
  - 已连接但过渡中：旋转动画 + "连接成功，正在加载投屏..."
  - 连接成功3秒后：渐出隐藏 → 露出投屏画面

**交互**：
- 单击Canvas（已连接）：坐标转换 → adb shell input tap
- 按住拖动：坐标映射 × 3倍距离 → adb shell input swipe
- 右键：默认菜单阻止（保留给功能键）
- 滚轮：模拟滑动

### 3.5 点击录制功能（MirrorPanel 右上角）

在 MirrorPanel 顶部工具栏右侧区域，新增两个竖向排列的图标按钮：

```
┌────────────────────────────────────────────────────────────┐
│ [≡][⊟] USB 1920×1080  连接 断开 返回 首页  │  X:320 Y:580 │
│                                              │  🔴  ← 录制  │
│                                              │  📋  ← 查看  │
├────────────────────────────────────────────────────────────┤
│                     [投屏画面]                              │
│                                                            │
└────────────────────────────────────────────────────────────┘
```

#### 3.5.1 录制按钮（RecordButton）

| 属性 | 说明 |
| :--- | :--- |
| 图标 | `CircleDot` 或 `Radio` (lucide-react) |
| 位置 | 右上角，竖向排列的第一个 |
| 状态 | 默认态 / 激活态（高亮+脉冲动画 `animate-pulse`） |
| 点击（未激活→激活） | 投屏区域覆盖半透明黑色蒙版（`z-30`），鼠标变为 `cursor: crosshair`，阻止事件穿透到底层画布 |
| 点击（激活→取消） | 移除蒙版，恢复鼠标样式 |
| Escape 键 | 退出录制模式（同点击取消） |

**蒙版交互**：
- 蒙版覆盖整个投屏内容区域（`flex-1` 区域），z-index 高于画布但低于顶部工具栏
- 蒙版上点击 → 阻止事件冒泡 → 获取点击坐标（设备物理坐标） → 弹出 `RecordClickFormDialog`
- 蒙版为半透明黑色（`bg-black/40`）

#### 3.5.2 查看按钮（ViewListButton）

| 属性 | 说明 |
| :--- | :--- |
| 图标 | `List` 或 `Database` (lucide-react) |
| 位置 | 右上角，竖向排列的第二个 |
| 点击 | 弹出 `RecordedClickListDialog`，从数据库加载已录制的点击模板 |

## 4. 弹窗/对话框

### 4.1 NewScriptDialog（新建脚本/目录）

支持Tab切换：脚本 / 目录

| Tab | 字段 | 控件 | 说明 |
| :--- | :--- | :--- | :--- |
| 脚本 | 脚本名称 | Input | 自动聚焦，必填 |
| 脚本 | 保存位置 | Button 组 | 根目录 / 已有文件夹列表按钮 |
| 目录 | 目录名称 | Input | 自动聚焦，必填 |
| 通用 | 操作 | 取消(outline) / 创建(primary) | 名称为空时禁用 |

### 4.2 NewStepDialog（新增/编辑步骤）

可同时用于添加和编辑模式。

| 区域 | 说明 |
| :--- | :--- |
| 步骤名称 | Input（默认跟随类型名，可自定义） |
| 类型选择 | 4 卡片：点击 / 输入 / 滑动 / 长按（点击切换时自动更新名称） |
| 点击参数 | X坐标、Y坐标 |
| 输入参数 | 文本内容 |
| 滑动参数 | 方向(↑↓←→) + 时长(秒) |
| 长按参数 | X坐标、Y坐标、按压时长(秒) |
| 操作 | 取消 / 添加(或保存) |

### 4.3 SettingsDialog（系统设置）

| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| 脚本超时时间（秒） | number | 1800 | 超过此时间自动终止 |
| 步骤执行间隔（秒） | number | 0.5 | 每步骤后的等待时间 |
| 最大重试次数 | number | 3 | 步骤失败后的重试次数 |

### 4.4 ConfirmDialog（确认弹窗）

通用确认框：title / description / cancel / confirm(destructive 红色变体)

### 4.5 RecordClickFormDialog（录制点击表单弹窗）

在录制模式下点击蒙版后弹出，用于保存录制的点击事件。

| 区域 | 说明 |
| :--- | :--- |
| 标题 | "录制点击" / "录制点击事件" |
| 名称 (name) | Input 文本框，必填，自动聚焦，placeholder："例如：点击微信" |
| 坐标 X | Input 数字，只读/禁用状态，自动填入鼠标按下位置的设备物理坐标 x |
| 坐标 Y | Input 数字，只读/禁用状态，自动填入鼠标按下位置的设备物理坐标 y |
| 类型 (type) | Select 或 Input 只读，自动填入 "click" |
| 操作 | 取消(outline) / 保存(primary) → 保存时校验名称非空 |

### 4.6 RecordedClickListDialog（录制模板列表弹窗）

点击查看按钮后弹出，展示所有已录制的点击模板。

| 区域 | 说明 |
| :--- | :--- |
| 标题 | "录制的点击事件" |
| 列表 | 表格/卡片列表，每行显示：名称、坐标(x, y)、类型、创建时间 |
| 行操作 | 右侧两个小按钮：编辑(铅笔图标) / 删除(垃圾桶图标) |
| 编辑模式 | 点击编辑 → 行内文本框编辑名称 → 保存/取消 |
| 分页 | 底部分页栏：上一页/页码/下一页，每页10条 |
| 空状态 | "暂无录制的点击事件" + 📭 图标 |
| 加载中 | 居中旋转动画 |
| 加载失败 | 错误提示 + 重试按钮 |

#### 3.6.3 面包屑导航（FileBreadcrumb）

| 区域 | 说明 |
| :--- | :--- |
| 展示 | 将当前路径按 `/` 分段显示，段间以 `>` 分隔 |
| 交互 | 点击非最后一段 → 导航到对应路径；最后一段纯文本 |
| 样式 | 可点击段：`text-primary hover:underline cursor-pointer`；当前段：`text-muted-foreground` |
| 根目录 | `/sdcard` 显示为 "sdcard"（首段省略前导 `/`） |

#### 3.6.4 文件列表

| 区域 | 组件 | 说明 |
| :--- | :--- | :--- |
| 容器 | ScrollArea | 列表滚动区域，高度自适应填充 |
| 列表项 | 自定义组件 `FileEntryItem` | 单行展示，含图标 + 名称 + 大小/日期 |
| 排序 | 目录在前，文件在后，各自按名称字母序（不区分大小写） |
| 选中 | 单击文件 → 高亮选中（`bg-accent`）→ 再次单击取消选中 |
| 目录交互 | 单击目录 → 导航进入该目录 |
| 文件双击 | 选中该文件并弹出提示可下载，或直接触发下载操作 |

**文件类型图标映射**：

| 类型 | 图标 (lucide-react) | 说明 |
| :--- | :--- | :--- |
| 目录 | `Folder` | 📁 |
| 图片 (.jpg/.png/.gif/.webp/.bmp) | `Image` | 🖼 |
| 视频 (.mp4/.avi/.mov/.mkv/.flv) | `Video` | 🎬 |
| 音频 (.mp3/.wav/.flac/.aac) | `Music` | 🎵 |
| APK (.apk) | `Package` | 📦 |
| 压缩包 (.zip/.rar/.7z/.tar/.gz) | `Archive` | 📚 |
| 其他 | `File` | 📄 |

**列表项显示**：
- 目录行：图标 + 名称 + 修改日期（右对齐）
- 文件行：图标 + 名称 + 文件大小（右对齐，自动转换单位 B/KB/MB/GB）

**空状态**：文件夹图标 + "该目录为空"

#### 3.6.5 操作按钮栏

| 按钮 | 行为 | 可用条件 |
| :--- | :--- | :--- |
| `📤 上传文件` (outline Button) | 弹出系统文件选择对话框 → 选文件 → ADB push → 刷新列表 | 始终可用 |
| `📥 下载选中` (outline Button) | 获取系统下载目录 → ADB pull → 通知结果 | 仅选中文件时可用，否则 disabled |

**交互规范**：
- 上传/下载过程中，对应按钮显示 loading 旋转动画并禁用
- 操作完成后自动刷新当前目录列表
- 操作结果通过 Toast 通知显示

#### 3.6.6 底部状态栏

| 内容 | 说明 |
| :--- | :--- |
| 当前路径 | 显示完整当前手机路径（如 `/sdcard/Download`） |
| 文件数量 | "N 项"（含目录和文件） |
| 示例 | `当前: /sdcard · 12 项` |

## 5. 状态管理（Zustand）

### scriptStore

| 状态 | 类型 | 说明 |

### deviceStore

| 状态 | 类型 | 说明 |
| :--- | :--- | :--- |
