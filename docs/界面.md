## 1. 设计目标

- **简洁高效**：核心功能一目了然，减少用户学习成本
- **双模式切换**：支持 LandingPage 全屏模式和侧栏编辑模式
- **实时反馈**：操作响应及时，状态变化清晰可见
- **可扩展性**：布局预留后续功能扩展空间

---

## 2. 整体布局

### 2.1 窗口尺寸

- 默认窗口大小：1280 × 900（支持拖拽缩放）
- 最小窗口大小：960 × 600
- 深色主题默认启用

## 3. 各区域详细设计

### 3.1 LandingPage（全屏初始页）

| 区域 | 元素 | 说明 |
| :--- | :--- | :--- |
| Icon Bar (40px) | [≡] 展开按钮 / [▼] 菜单 / [⚙] 设置 | 左上≡切换三栏模式 |
| 内容区 | 80×80 虚线手机图标 + 连接设备按钮 + 说明文字 | 引导用户连接设备 |
| 底部栏 (28px) | ● DISCONNECTED / v1.0.0 | 连接状态 + 版本号 |

---

### 3.2 第1栏 - ScriptPanel（脚本管理栏）

**固定宽度**：240px

| 区域 | 组件 | 说明 |
| :--- | :--- | :--- |
| 标题 | h1 AutoClick | 粗体，底部边框 |
| 新建按钮 | outline Button | `+ 新建脚本` → NewScriptDialog |
| 脚本列表 | ScrollArea | 文件夹树 + Card 脚本项 |
| 文件夹 | Chevron + FolderIcon + 名称 + Badge | 点击展开/收起 |
| 脚本项 | Card + FileIcon + 名称 + [🗑] | 选中高亮显示删除按钮 |
| 底部 | 导入 / 导出 / v1.0.0 / [⚙] | 设置 → SettingsDialog |

**交互**：
- 点击文件夹 → 展开/收起子脚本
- 点击脚本 → 选中高亮，StepPanel 刷新
- 点击 [🗑] → ConfirmDialog 确认删除
- 点击新建 → NewScriptDialog（名称 + 保存位置）

---

### 3.3 第2栏 - StepPanel（步骤栏）

**固定宽度**：340px

| 区域 | 组件 | 说明 |
| :--- | :--- | :--- |
| 顶部工具栏 | ← 返回 + 名称(N步) / ▶运行 ●录制 ︙编辑 | 40px |
| 添加步骤 | outline Button | `+ 添加步骤` → NewStepDialog |
| 步骤列表 | ScrollArea | 序号 + 图标 + 类型 + 描述 |
| 操作行 | [更多▼] (编辑/删除) + [运行] | 选中步骤后显示 |
| 底部状态 | ● Step 1/5 / Status: Success | 进度 + 执行状态 |

**步骤类型图标**：

| 类型 | 图标组件 | 示例 |
| :--- | :--- | :--- |
| click | MousePointerClick | Click (320, 580) |
| type | Keyboard | Type "admin_user_01" |
| swipe | ArrowUpDown | Swipe Up (1.2s) |
| script | FileCode | Scripts - run.js |

---

### 3.4 第3栏 - MirrorPanel（投屏区域）

**宽度**：自适应（flex-1）

**顶部工具栏**（40px）：
- [◀] 收起侧边栏 → 返回 LandingPage
- 投屏 / USB / 1920×1080（连接信息）
- 连接 / 断开 / 刷新（设备控制）
- X: 320 Y: 580（鼠标坐标）
- Badge "未连接"（断开时显示）

**内容区**：
- 未连接：80×80 虚线手机图标 + 连接设备按钮 + 说明文字
- 已连接：360×720 手机屏幕占位（圆角+阴影+十字光标）

**底部设备栏**（40px）：
- 已连接：● CONNECTED Pixel 6 / 1080×2400 85%
- 断开：● DISCONNECTED

## 4. 弹窗/对话框

### 4.1 NewScriptDialog（新建脚本）

| 字段 | 控件 | 说明 |
| :--- | :--- | :--- |
| 脚本名称 | Input | 自动聚焦，必填 |
| 保存位置 | Button 组 | 根目录 / 已有文件夹 |
| 操作 | 取消(outline) / 创建(primary) | 名称为空时禁用 |

### 4.2 NewStepDialog（新增步骤）

| 区域 | 说明 |
| :--- | :--- |
| 类型选择 | 4 卡片：点击 / 输入 / 滑动 / 脚本 |
| 点击参数 | X坐标、Y坐标、描述（可选） |
| 输入参数 | 文本内容 |
| 滑动参数 | 方向(↑↓←→) + 时长(秒) |
| 脚本参数 | 子脚本名称 |
| 操作 | 取消 / 添加 |

### 4.3 SettingsDialog（系统设置）

- 宽度：560px
- 侧边栏标签页切换

| 标签页 | 配置项 |
| :--- | :--- |
| 设备 | ADB 路径、scrcpy 路径、截图保存目录 |
| 脚本 | 超时时间(s)、步骤间隔(s)、重试次数 |

### 4.4 ConfirmDialog（确认弹窗）

通用确认框：title / description / cancel / confirm(destructive 红色变体)

## 5. 状态管理（Zustand）

### scriptStore

| 状态 | 类型 | 说明 |
| :--- | :--- | :--- |
| scripts | Script[] | 脚本列表（文件夹+脚本层级） |
| currentScriptId | string \| null | 当前选中脚本 |
| selectedStepId | string \| null | 当前选中步骤 |
| executingStepIndex | number \| null | 执行中步骤序号 |
| expandedFolders | Set\<string\> | 已展开文件夹 ID |

### deviceStore

| 状态 | 类型 | 说明 |
| :--- | :--- | :--- |
| isConnected | boolean | 设备连接状态 |
| deviceInfo | object \| null | {model, resolution, battery} |
