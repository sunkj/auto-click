## 1. 设计目标

- **简洁高效**：核心功能一目了然，减少用户学习成本
- **实时反馈**：操作响应及时，状态变化清晰可见
- **可扩展性**：布局预留后续功能扩展空间
- **跨平台一致**：Windows与macOS保持统一的视觉和交互体验

---

## 2. 整体布局

### 2.1 窗口尺寸

- 默认窗口大小：1200 x 860（支持拖拽缩放）
- 最小窗口大小：960 x 600

### 2.2 布局结构

整体采用四区域布局：

| 区域 | 位置 | 宽度 | 说明 |
| :--- | :--- | :--- | :--- |
| 菜单栏 | 顶部 | 100% | 文件、设备、视图、帮助等菜单 |
| 左侧脚本管理栏 | 左侧 | 260px | 脚本分组树、脚本列表 |
| 中间投屏区域 | 中央 | 自适应 | 手机画面实时显示 |
| 右侧控制面板 | 右侧 | 280px | 操作按钮、设备信息、通知配置 |
| 底部日志区 | 底部 | 高度180px | 脚本运行日志、控制台输出 |

## 3. 各区域详细设计

### 3.1 菜单栏

菜单栏包含以下菜单项：

| 菜单 | 子项 | 功能 |
| :--- | :--- | :--- |
| 文件 | 新建脚本 | 创建空白脚本 |
| | 导入脚本 | 导入本地.js文件 |
| | 导出脚本 | 导出选中脚本 |
| | 退出 | 退出应用 |
| 设备 | 连接设备 | 手动刷新设备列表 |
| | 断开设备 | 断开当前连接 |
| | 设备信息 | 查看设备详情 |
| 视图 | 日志面板 | 显示/隐藏日志区 |
| | 全屏 | 投屏区域全屏 |
| 帮助 | 使用文档 | 打开帮助文档 |
| | 关于 | 版本信息 |

### 3.2 左侧脚本管理栏

#### 3.2.1 区域组成

- **顶部工具栏**：标题显示“脚本管理”，右侧有新增分组按钮（+）
- **中间内容区**：脚本分组树形结构，支持展开/收起
- **底部操作栏**：导入、导出、删除按钮

#### 3.2.2 交互说明

| 操作 | 交互反馈 |
| :--- | :--- |
| 点击分组 | 展开/收起脚本列表 |
| 双击脚本 | 在编辑器打开脚本 |
| 右键脚本 | 显示上下文菜单（重命名、删除、复制、导出、运行） |
| 点击新增分组按钮 | 弹出新建分组对话框 |
| 拖拽脚本 | 移动到其他分组 |

### 3.3 中间投屏区域

#### 3.3.1 区域组成

- **顶部信息栏**：显示设备名称、分辨率、连接状态
- **中央画布区**：Canvas画布，实时显示手机画面
- **底部状态栏**：显示连接状态提示和操作按钮（刷新、设置）

#### 3.3.2 状态说明

| 状态 | 显示内容 |
| :--- | :--- |
| 已连接 | 显示手机画面，顶部显示设备名称和分辨率 |
| 连接中 | 显示加载动画 + "正在连接设备..." |
| 未连接 | 显示灰色占位图 + "请连接Android设备" |
| 断连 | 显示提示 + 自动重连倒计时 |

#### 3.3.3 鼠标操作

| 操作 | 效果 |
| :--- | :--- |
| 单击 | 模拟手指点击 |
| 双击 | 模拟双击 |
| 按住拖动 | 模拟滑动 |
| 右键 | 模拟返回键 |
| 滚轮 | 上下滑动页面 |

### 3.4 右侧控制面板

#### 3.4.1 区域组成

面板从上到下包含以下模块：

1. **设备信息模块**
   - 显示设备型号、分辨率、电量、连接状态

2. **脚本控制模块**
   - 运行按钮（▶）
   - 停止按钮（■）
   - 录制按钮（●）

3. **脚本编辑器模块**
   - 可折叠/展开
   - 代码编辑区，支持语法高亮
   - 支持手动编辑和微调

4. **通知配置模块**
   - 平台选择（飞书、钉钉、微信）
   - Webhook地址输入框
   - 测试发送按钮

#### 3.4.2 功能按钮说明

| 按钮 | 图标 | 功能 |
| :--- | :--- | :--- |
| 运行 | ▶ | 执行当前选中的脚本 |
| 停止 | ■ | 停止正在运行的脚本 |
| 录制 | ● | 开始录制用户操作，再次点击停止录制并生成脚本 |
| 设置 | ⚙ | 打开投屏设置（帧率、画质、端口等） |
| 刷新 | ↻ | 刷新设备列表 |

### 3.5 底部日志区

#### 3.5.1 区域组成

- **工具栏**：日志级别筛选标签（运行、错误、警告、信息）、清空按钮、收起按钮
- **日志列表**：按时间顺序显示日志条目，每条包含时间戳、级别、内容

#### 3.5.2 交互说明

| 操作 | 功能 |
| :--- | :--- |
| 点击日志级别标签 | 按级别筛选显示 |
| 双击日志行 | 复制完整日志内容 |
| 点击清空 | 清空当前日志面板 |
| 点击收起 | 折叠日志区（显示底部条） |

#### 3.5.3 日志级别样式

| 级别 | 样式 |
| :--- | :--- |
| INFO | 蓝色 |
| WARN | 黄色 |
| ERROR | 红色 |
| 运行中 | 绿色闪烁 |

## 4. 弹窗/对话框设计

### 4.1 新建脚本对话框

包含以下字段：
- 脚本名称（文本输入框）
- 脚本分组（下拉选择，包含现有分组）
- 脚本模板（下拉选择：空脚本、录制模板等）

底部按钮：取消、创建

### 4.2 新建分组对话框

包含以下字段：
- 分组名称（文本输入框）

底部按钮：取消、创建

### 4.3 定时任务设置对话框

包含以下配置项：

| 配置项 | 控件类型 | 选项/说明 |
| :--- | :--- | :--- |
| 执行方式 | 单选按钮 | 单次 / 重复 / 循环 |
| 重复规则 | 下拉选择 + 时间选择 | 每天/每周/每月 + 具体时间 |
| Cron表达式 | 只读展示 | 自动生成，高级用户可手动编辑 |
| 结束条件 | 复选框 | 执行次数（设置次数）/ 到期时间（选择日期） |

底部按钮：取消、保存、立即运行

### 4.4 脚本微调面板

该面板可折叠，展开后包含以下选项：

| 选项 | 控件类型 | 说明 |
| :--- | :--- | :--- |
| 延迟执行 | 复选框 + 数字输入 | 脚本启动前延迟时间（毫秒） |
| 坐标随机扩散 | 复选框 + 数字输入 | 点击坐标随机偏移范围（像素） |
| 点击前等待 | 复选框 + 数字输入 | 每次点击前等待时间（毫秒） |
| 截图保存 | 复选框 | 失败时自动截图保存 |

### 4.5 Webhook配置对话框

包含以下字段：
- 平台选择（飞书、钉钉、微信）
- Webhook URL（文本输入框）
- 签名密钥（文本输入框，可选）
- 测试发送按钮

底部按钮：取消、保存

## 6. 交互流程

### 6.1 连接设备流程

打开应用后自动检测设备。检测到设备时直接显示投屏画面；未检测到设备时显示“未连接”提示，用户可点击刷新按钮手动连接或查看驱动安装指引。

### 6.2 录制脚本流程

用户点击录制按钮后，按钮进入高亮闪烁状态表示录制中。用户在投屏区域的每一次点击、滑动、输入操作都会被自动记录并生成对应代码。再次点击停止录制按钮，脚本保存到当前选中的分组中。

### 6.3 运行脚本流程

用户选中脚本后点击运行按钮，日志区显示开始执行信息。脚本执行过程中，日志区实时输出执行步骤。执行成功时显示成功日志并发送通知；执行失败时显示错误日志，发送通知并附带截图。

### 6.4 定时任务流程

用户设置定时任务后，任务进入调度队列。到达指定时间时自动触发脚本执行。执行结果通过通知模块发送到配置的即时聊天工具。

## 7. 响应式适配

根据窗口宽度变化调整布局：

| 窗口宽度 | 侧边栏状态 | 右侧面板状态 | 投屏区域 |
| :--- | :--- | :--- | :--- |
| 大于等于1200px | 260px展开 | 280px展开 | 自适应 |
| 960px至1199px | 220px展开 | 240px展开 | 自适应 |
| 小于960px | 折叠为图标 | 折叠为图标 | 全宽显示 |

折叠状态下，鼠标悬停图标时显示浮层菜单。
