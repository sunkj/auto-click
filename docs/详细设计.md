## 1. 文档概述

### 1.1 设计目标
本文档基于《AutoClick - UI设计文档》V1.0，提供详细的技术设计方案，指导开发人员使用**React + shadcn/ui**进行编码实现。

### 1.2 技术选型

| 层级 | 技术选型 | 说明 |
| :--- | :--- | :--- |
| **桌面框架** | Electron | 跨平台桌面应用容器 |
| **前端框架** | React 18 | 核心UI框架 |
| **UI组件库** | shadcn/ui | 现代组件库，基于Radix UI + TailwindCSS，支持深色主题 |
| **样式方案** | TailwindCSS | 与shadcn/ui完美集成 |
| **状态管理** | Zustand | 轻量级状态管理 |
| **路由管理** | React Router DOM | 预留扩展能力 |
| **设备连接** | @devicefarmer/adb | Node.js ADB客户端 |
| **脚本引擎** | vm2 | 沙箱执行用户脚本 |
| **本地存储** | better-sqlite3 + 文件系统 | 元数据存储与脚本文件管理 |
| **屏幕流** | jpeg-over-websocket | 低延迟投屏方案 |

## 2. 系统架构设计

### 2.1 整体架构图

采用**Electron主进程 + React渲染进程**分离架构：

| 进程 | 职责 | 技术栈 |
| :--- | :--- | :--- |
| **主进程** | ADB设备通信、脚本执行、文件读写、屏幕流服务 | Node.js + Electron |
| **渲染进程** | UI渲染、用户交互、状态管理、实时画面显示 | React + shadcn/ui + Zustand |

**通信方式**：Electron IPC（主进程与渲染进程之间的异步事件通信）

### 2.2 模块划分

| 模块 | 位置 | 职责 |
| :--- | :--- | :--- |
| **脚本管理模块** | 渲染进程 | 脚本列表展示、导入/导出、选中切换 |
| **步骤列表模块** | 渲染进程 | 步骤展示、增删改查、单步/全部执行 |
| **投屏模块** | 渲染进程 + 主进程 | 设备连接、画面显示、触摸模拟 |
| **设备管理模块** | 主进程 | ADB命令封装、设备扫描、连接维护 |
| **脚本引擎模块** | 主进程 | 脚本加载、沙箱执行、步骤调度 |
| **存储模块** | 主进程 | 数据库操作、脚本文件读写 |

### 3.1 组件映射

| UI设计元素 | shadcn/ui组件 | 说明 |
| :--- | :--- | :--- |
| 脚本列表 | ScrollArea + Card | 可滚动列表，每个脚本项使用Card |
| 步骤列表 | ScrollArea + Table | 表格形式展示步骤 |
| 按钮 | Button | 支持变体：default / destructive / outline / ghost |

| 设置菜单 | DropdownMenu | 下拉菜单 |
| 编辑弹窗 | Dialog + Form | 步骤编辑表单 |
| 设备连接状态 | Badge | 显示CONNECTED/DISCONNECTED |
| 通知提示 | Toast | 操作反馈 |
| 确认操作 | AlertDialog | 删除确认等 |
| 加载状态 | Skeleton / Spinner | 异步操作反馈 |
| 投屏画布 | Canvas（原生） | 非shadcn组件，需要自定义 |

### 3.2 主题配置

shadcn/ui原生支持深色主题，通过CSS变量定义颜色，与设计文档的颜色规范对应：

| 设计规范颜色 | shadcn/ui CSS变量映射 |
| :--- | :--- |
| 主色调 #1890FF | `--primary` |
| 成功 #52C41A | 复用`--primary`或自定义`--success` |
| 警告 #FAAD14 | 复用`--warning` |
| 错误 #F5222D | `--destructive` |
| 背景色 #1E1E1E | `--background` |
| 次级背景 #2D2D2D | `--secondary` |
| 边框色 #3F3F3F | `--border` |
| 选中高亮 | `--accent` + `--ring` |

**实现方式**：在项目的`globals.css`中定义深色主题的CSS变量，通过`dark`类名切换。

## 4. 状态管理设计（Zustand）

### 4.1 Store结构

| Store名称 | 管理状态 | 主要操作 |
| :--- | :--- | :--- |
| **scriptStore** | 脚本列表、当前脚本、步骤列表、选中步骤、执行中步骤索引 | 加载脚本、选中脚本、导入/导出、增删改步骤 |
| **deviceStore** | 连接状态、设备信息、屏幕流地址 | 连接设备、断开、点击、滑动、输入文字、返回 |
| **uiStore** | 主题、侧边栏宽度、设置面板开关、通知消息 | 切换主题、开关设置、显示通知 |

### 4.2 状态流转说明

- **脚本选中流程**：用户点击脚本 → scriptStore更新currentScriptId → 触发步骤列表加载 → 步骤栏重新渲染
- **步骤执行流程**：用户点击运行 → 主进程ScriptEngine调度 → 通过IPC推送进度 → scriptStore更新executingStepIndex → 步骤高亮更新
- **设备连接流程**：用户点击连接按钮 → deviceStore调用连接操作 → 主进程扫描ADB设备 → 返回结果更新isConnected → 投屏区域切换显示

## 5. 模块详细设计

### 5.1 第1栏 - 脚本管理栏

| 子组件 | shadcn/ui组件 | 功能描述 |
| :--- | :--- | :--- |
| 标题区域 | 原生div + typography样式 | 显示软件名称AutoClick |
| 脚本列表 | ScrollArea + Card | 展示所有脚本，支持选中高亮 |
| 脚本项操作 | Button (ghost变体) | 每个脚本项右侧显示运行按钮（▶） |
| 导入按钮 | Button | 打开文件选择器导入脚本 |
| 导出按钮 | Button | 导出当前选中脚本 |
| 设置按钮 | DropdownMenu | 下拉显示设置选项 |
| 版本号 | 原生span | 显示版本号文本 |

**交互说明**：
- 点击脚本Card：选中该脚本，通过scriptStore更新状态，触发步骤栏刷新
- 点击脚本旁的运行按钮：触发脚本全量执行，调用主进程ScriptEngine
- 导入/导出：通过IPC调用主进程文件对话框，完成后刷新列表

### 5.2 第2栏 - 脚本步骤栏

| 子组件 | shadcn/ui组件 | 功能描述 |
| :--- | :--- | :--- |
| 头部区域 | 原生div + Button | 显示脚本名称、全量运行按钮 |
| 步骤表格 | Table | 展示步骤序号、类型、参数描述 |
| 步骤操作行 | Button组 | 编辑/删除/运行三个按钮，选中步骤后显示 |
| 编辑弹窗 | Dialog + Form | 编辑步骤参数的表单弹窗 |

**步骤类型显示格式**：

| 类型 | 显示内容 | 示例 |
| :--- | :--- | :--- |
| click | Click + 坐标 + 描述 | Click (320, 580) - "Login Button" |
| type | Type + 输入内容 | Type "admin_user_01" |
| swipe | Swipe + 方向 + 时长 | Swipe Up (1.2s) |
| script | Scripts + 脚本名称 | Scripts - run.js |

**交互说明**：
- 点击表格行：选中该步骤，高亮显示，底部显示操作行
- 点击编辑按钮：打开Dialog弹窗，表单预填当前步骤参数，保存后更新步骤列表
- 点击删除按钮：弹出AlertDialog确认，确认后删除步骤并持久化
- 点击运行按钮：单独执行该步骤，调用主进程ScriptEngine
- 脚本执行中：通过IPCEvent更新executingStepIndex，对应表格行高亮（使用不同背景色）

### 5.3 第3栏 - 投屏区域

| 子组件 | shadcn/ui组件 | 功能描述 |
| :--- | :--- | :--- |
| 未连接状态 | Button + 提示文本 | 中央显示连接按钮和说明文字 |
| 已连接状态 | Canvas（原生） | 显示手机实时投屏画面 |
| 设备信息栏 | Badge + 原生div | 显示设备名称、分辨率等信息 |

**交互说明**：
- 点击连接按钮：调用deviceStore.connect()，触发主进程ADB扫描
- 单击Canvas：计算坐标，调用deviceStore.tap()，通过ADB发送点击事件
- 双击Canvas：调用deviceStore.tap()两次，或发送双击命令
- 按住并拖动：记录起始和结束坐标，调用deviceStore.swipe()
- 右键点击Canvas：阻止默认菜单，调用deviceStore.pressBack()
- 滚轮滚动：根据滚动方向，调用deviceStore.swipe()模拟滑动

**坐标映射**：需要实现坐标转换函数，将Canvas上的鼠标坐标映射到设备实际分辨率。

### 5.4 底部状态栏

| 元素 | shadcn/ui组件 | 功能描述 |
| :--- | :--- | :--- |
| 状态文本 | 原生span | 显示DISCONNECTED / CONNECTED |
| 设备名称 | Badge | 连接成功后显示设备名称 |

- 订阅deviceStore中的isConnected和deviceInfo状态，自动更新显示

## 6. IPC通信设计

### 6.1 通信频道定义

| 频道名称 | 方向 | 说明 |
| :--- | :--- | :--- |
| `scripts:load` | 渲染 → 主 | 获取所有脚本列表 |
| `scripts:import` | 渲染 → 主 | 导入脚本文件 |
| `scripts:export` | 渲染 → 主 | 导出脚本文件 |
| `steps:load` | 渲染 → 主 | 加载指定脚本的步骤列表 |
| `steps:update` | 渲染 → 主 | 更新步骤列表（全量替换） |
| `device:connect` | 渲染 → 主 | 连接Android设备 |
| `device:command` | 渲染 → 主 | 发送点击/滑动/输入等命令 |
| `script:run` | 渲染 → 主 | 执行脚本（全量/单步） |
| `event:step-progress` | 主 → 渲染 | 步骤执行进度推送 |
| `event:device-status` | 主 → 渲染 | 设备连接状态变化推送 |
| `event:screen-frame` | 主 → 渲染 | 投屏画面帧数据推送 |

### 6.2 预加载脚本暴露的API

渲染进程通过`window.electronAPI`访问主进程功能，主要方法：

| 方法名 | 参数 | 返回值 | 说明 |
| :--- | :--- | :--- | :--- |
| `getScripts()` | 无 | `Promise<Script[]>` | 获取脚本列表 |
| `importScript(filePath)` | `string` | `Promise<Script>` | 导入脚本 |
| `exportScript(scriptId, targetPath)` | `string, string` | `Promise<void>` | 导出脚本 |
| `loadSteps(scriptId)` | `string` | `Promise<Step[]>` | 加载步骤 |
| `updateSteps(scriptId, steps)` | `string, Step[]` | `Promise<void>` | 更新步骤 |
| `connectDevice()` | 无 | `Promise<DeviceInfo>` | 连接设备 |
| `sendTap(x, y)` | `number, number` | `Promise<void>` | 发送点击 |
| `sendSwipe(x1,y1,x2,y2,duration)` | 参数 | `Promise<void>` | 发送滑动 |
| `runScript(scriptId, mode, stepIndex)` | 参数 | `Promise<void>` | 执行脚本 |
| `onStepProgress(callback)` | 函数 | `() => void` | 监听步骤进度 |

## 8. 关键流程设计

### 8.1 应用启动流程

1. Electron主进程启动，初始化数据库连接
2. 加载预加载脚本，暴露IPC API
3. 创建BrowserWindow，加载React应用
4. React应用初始化Zustand Stores
5. scriptStore调用`loadScripts()`，通过IPC获取脚本列表
6. UI渲染三栏布局，底部状态栏显示未连接状态

### 8.2 设备连接与投屏流程

1. 用户点击“连接设备”按钮
2. deviceStore调用`connectDevice()` IPC
3. 主进程执行ADB扫描：`adb devices`
4. 找到设备后，建立连接，获取设备信息（分辨率、型号等）
5. 启动屏幕流服务（方案：`adb exec-out screencap -p` 或 minicap）
6. 通过`event:device-status`推送连接成功事件
7. 渲染进程更新isConnected状态，投屏区域开始接收并渲染画面帧
8. 底部状态栏显示CONNECTED和设备名称

### 8.3 脚本执行与步骤高亮流程

1. 用户选择脚本，点击“运行”按钮
2. 渲染进程发送`script:run` IPC（携带scriptId）
3. 主进程ScriptEngine加载脚本文件，解析steps数组
4. 循环遍历steps，依次执行：
   - 执行前发送`event:step-progress`（status: 'start', stepIndex）
   - 渲染进程更新executingStepIndex，高亮对应步骤
   - 根据步骤类型调用DeviceManager对应ADB命令
   - 执行完成后发送`event:step-progress`（status: 'end', stepIndex）
5. 所有步骤执行完毕，发送`event:script-complete`
6. 渲染进程清除executingStepIndex，显示完成通知

### 8.4 步骤编辑流程

1. 用户点击步骤表格中的某一行，选中步骤
2. scriptStore更新selectedStepIndex
3. 步骤列表下方显示操作行（编辑、删除、运行）
4. 点击“编辑”按钮：
   - 打开Dialog弹窗
   - 使用shadcn/ui的Form组件，预填当前步骤参数
   - 用户修改参数后提交
   - 更新scriptStore中的currentSteps数组
   - 调用`steps:update` IPC，持久化到数据库和脚本文件
5. 点击“删除”按钮：
   - 弹出AlertDialog确认
   - 确认后从currentSteps数组中删除
   - 重新排序剩余步骤的index
   - 调用`steps:update` IPC持久化

## 10. 异常处理设计

| 异常场景 | 处理方式 |
| :--- | :--- |
| 设备未连接时执行脚本 | 按钮禁用状态 + Toast提示“请先连接设备” |
| 设备连接失败 | Toast错误提示，投屏区域显示错误信息 |
| 脚本文件格式错误 | 导入时校验，提示“脚本格式不正确” |
| 脚本执行中设备断开 | 中断执行，Toast提示，底部状态栏更新为DISCONNECTED |
| 步骤编辑时数据校验失败 | Form组件显示字段级错误提示 |
| ADB命令执行超时 | 设置超时（5秒），超时后中断并提示 |

## 11. 性能优化建议

| 优化点 | 方案 |
| :--- | :--- |
| 步骤列表渲染 | 使用shadcn/ui的Table组件自带虚拟滚动，或react-window优化（步骤>500时） |
| 投屏流畅度 | 使用WebSocket + JPEG帧传输，限制帧率30fps，使用requestAnimationFrame渲染 |
| 脚本导入解析 | 大文件异步解析，显示Loading Skeleton |
| IPC通信 | 避免频繁大数据传输，屏幕流单独使用WebSocket通道 |
