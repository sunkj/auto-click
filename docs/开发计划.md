| 项目 | 内容 |

| **状态** | **已完成** (2026-06-14) |

**任务清单**：
- [x] 实现存储模块（SQLite初始化）— 由 Iteration 3 service 层覆盖
- [x] 实现导入功能（文件对话框 → 读取 .js 文件 → 解析 JSON → 入库）
- [x] 实现导出功能（选中脚本 → 保存对话框 → 写入 .js 文件）
- [x] 列表自动刷新（导入后自动 loadScripts）
- [x] 导入格式校验（JSON 格式校验 + 文件类型过滤）

**实现说明**：
- 导入：`script:import` IPC → `dialog.showOpenDialog` → 读取文件 → 解析 JSON → `createScript` + `addStep` 循环入库
- 导出：`script:export` IPC → `getScriptById` + `getStepsByScriptId` → `dialog.showSaveDialog` → 写入格式化的 `.js` 文件
- 导出按钮在未选中脚本时 disabled
- 支持的导入格式：首行为 `//` 注释的 JSON 数组文件

**验收标准**：
- ✅ 可从本地导入`.js`脚本文件

### Iteration 8：投屏画面显示 ✅

| 项目 | 内容 |
| :--- | :--- |
| **目标** | 实时显示手机屏幕画面 |
| **预计工时** | 12小时 → 4小时 |
| **优先级** | P1（重要） |
| **状态** | **已完成** (2026-06-14) |

**任务清单**：
- [x] 确定投屏方案（@yume-chan/scrcpy + TinyH264 解码）
- [x] 实现主进程 scrcpy 会话管理（AdbScrcpyClient）
- [x] 实现视频流读取 → IPC 帧事件推送
- [x] Canvas 渲染（MirrorPanel 画布组件）
- [x] 处理连接/断开时的画面切换
- [x] 画布自适应缩放

**实现说明**：
- 主进程启动 ScrcpyServer，通过 AdbScrcpyClient.videoStream 读取 H264 帧
- 视频帧通过 IPC（scrcpy:frame）发送到渲染进程
- 渲染进程 MirrorPanel 使用 Canvas 显示
- scrcpy-server.jar 通过 fetch-scrcpy-server 自动获取后推送到设备

**验收标准**：
- ✅ 连接设备后 scrcpy 会话启动
- ✅ 视频帧通过 IPC 推送到渲染进程
