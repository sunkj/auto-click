# 用户提问记录 - 手机投屏控制软件设计对话

## 第一轮：需求文档

做一个电脑端的手机投屏软件，需要有如下这些功能，帮我整理一份详细的需求文档，另外，你可以结合现在市面上的类似软件，给一些参考和建议
1）支持手机投屏到电脑上，暂时只需要先支持连接一台手机
2）支持鼠标点击，拖动，滑动，模拟手指的操作
3）支持编写js脚本模拟鼠标点击，拖动，滑动等功能
4）支持录制功能，自动生成js脚本，同时支持手动微调，比如：设置延迟执行，点击坐标随机扩散
5）支持脚本管理，包括脚本分组，导入，下载，上传，删除，新增
6）支持脚本运行，定时运行，重复运行
7）脚本运行需要可以绑定机器人，通知到即时聊天软件，例如：飞书，微信，钉钉
