## 2. 新增"点击录制"功能 — 需求沟通

提出录制点击事件的需求：
- 手动在投屏区域点击，记录坐标存储起来
- 数据字段：名称、坐标、类型
- 可供 AI 助手使用，或在添加步骤时直接选择

### 需求细化确认

**Q: 数据存储用独立表还是复用现有步骤表？**
A: 存入独立表 `recorded_clicks`。

**Q: 查看按钮点击后弹窗还是侧边面板？**
A: 弹出框，列表展示所有数据，支持分页。

**Q: 列表操作按钮样式？**
A: 每条记录右侧有 delete/edit 操作按钮。

## 5. UI 修改一轮

**问题：两个按钮位置不对，要下来到 MirrorPanel 的 top bar 下面，上间距留 20，右边留 20**
→ 从 Top Bar 移除，改为浮动在投屏区域右上角（`absolute top-5 right-5`）

**问题：录屏蒙版只需要覆盖手机画面区域**
→ 蒙版改为只覆盖 canvas 区域，不覆盖工具栏和底部栏

**问题：录制弹窗的类型字段参照添加步骤弹窗样式，只保留点击类型**
→ 把 disabled Input 改为卡片式选择器

**问题：查看记录窗坐标信息显示大一点，右边空格比较多**
→ 坐标从 Badge 改为 `text-sm font-mono tabular-nums`

**问题：查看记录窗右上角加 close 按钮**
→ 新增 `CircleX` 图标关闭按钮

## 7. UI 修改三轮 — 修复显示问题

**问题：手机屏幕区域显示不出来了，只有一个黑块**
→ 定位到 `inline-flex` 包裹层破坏了 canvas 布局
→ 移除包裹层，改用 `ResizeObserver` + `canvasRect` 精确定位蒙版

**问题：两个按钮独立到单独的组件**
→ 提取 `RecordActionButtons.tsx`

## 8. 滑动按钮需求

**问题：手机屏幕右侧居中位置添加向上/向下滑动按钮**
→ 基于 `canvasRect` 定位，画布右侧居中

**问题：滑动按钮需要在 window.electronAPI?.screenMirror 实现两个方法**
