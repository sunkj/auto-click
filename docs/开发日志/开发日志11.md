## 1. 初始上下文支持

### 1.1 新建脚本弹框支持设置初始Context

**需求：** 新建脚本弹框需要支持设置初始context

→ 在 NewScriptDialog 中添加初始 Context 折叠面板，支持添加/删除 key-value 对。

### 1.2 新建脚本 context 样式问题

**需求：** 新建脚本 context 设置，样式有问题，太多之后UI会超出

→ context 列表容器添加 `max-h-[180px] overflow-y-auto`，条目过多时内部滚动。

### 1.3 编辑脚本时也支持修改初始上下文

**需求：** 编辑脚本的时候也需要支持修改

→ StepPanel 编辑脚本弹窗同步增加初始上下文编辑功能，保存时通过 `updateScript` 写入。

### 1.4 默认展开与改名

**需求：** 初始context不用隐藏起来，默认展开，改成初始上下文

→ 默认展开，文字改为「初始上下文」。

### 1.5 改为普通标签样式，调整布局顺序

**需求：** 初始上下文，不要收起展开，直接改成跟上面脚本名称一样的label，目录往上移动到脚本名称上面

→ 去掉折叠按钮，改为普通 label 直接显示编辑列表；目录选择器移到脚本名称上方。

## 2. 添加步骤弹框 UI 优化

### 2.1 前置条件/写入上下文的间距与命名

**需求：** 添加步骤 编辑框，前置条件，写入context加一点上间距，写入context重命名为写入上下文

→ 前置条件上方 `mt-3`，写入上下文上方 `mt-2`；「写入 Context」→「写入上下文」。

### 2.2 Key下拉选择，Value改名

**需求：** 前置条件 Context Key 改成 选择Key；写入上下文 key 改成选择key，value 改成 设置value；context的key下拉选择，key列表数据全部从脚本初始context里面获取，不支持新增

→ 两个 Key 字段改为 `<select>` 下拉框，数据源为脚本初始上下文 key 列表；Value 字段改为「设置 Value」。

### 2.3 Value 不支持模板

**需求：** 设置 Value 不支持设模板，必须是手动设置好值

→ placeholder 改为「设置值」。

### 2.4 行上下 padding 统一

**需求：** 添加步骤 下面的行上下padding不一样，请改成一样的，改成10px

→ 步骤类型卡片 `py-3`→`py-[10px]`，折叠标题 `py-2`→`py-[10px]`，统一为 10px。

### 2.5 弹框宽度

**需求：** 添加步骤 的宽度设置到 680px

→ Dialog 添加 `className="max-w-[680px]"`。

### 2.6 类型选择按钮缩小

**需求：** 添加步骤 选择类型，每一个类型宽度改小一半

→ `grid-cols-4` → `grid-cols-8`。

### 2.7 类型选择按钮进一步缩小

**需求：** 添加步骤 选择类型，每一个类型高度和图标，宽度都再缩小一点

→ `grid-cols-8 gap-2` → `grid-cols-9 gap-1.5`，`py-[10px]` → `py-[6px]`，`h-5 w-5` → `h-4 w-4`。

### 2.8 AI 类型高度溢出

**需求：** 如果选择AI类型，高度有点超出了

→ textarea `rows={6}` → `rows={4}`。

## 3. Bug 修复

### 3.1 脚本数据丢失

**需求：** 为啥我的脚本数据没有了

→ 数据库 `synchronize: false`，之前给 `ScriptEntity` 加了 `initial_context` 列但 DDL 未同步，导致写库失败。在 `data-source.ts` 中补充了 DDL 列定义和幂等 ALTER TABLE 迁移。

### 3.2 脚本初始上下文不能保存

**需求：** 脚本的初始context不能保存

→ `ScriptRepository.update()` 方法缺失 `initialContext` 字段处理，补上 `if (updates.initialContext !== undefined) entity.initialContext = updates.initialContext`。

### 3.3 前置条件不生效

**需求：** step执行的前置条件不对，我在初始context里面设置了a=1,b=2，在step1的前置条件加了a=1就终止，然而并没有

→ `ScriptLoader.load()` 返回的 `ScriptObject` 没有包含 `initialContext`，引擎拿不到初始上下文的值。补上 `initialContext: entity.initialContext || undefined`。

### 3.4 步骤列表显示值

**需求：** step列表前置条件、输出，把value也显示出来

→ StepPanel 中 badge 改为 `key=value` 格式显示。
