## 1. 概述

### 1.1 设计目标
为 AutoClick 设计"点击录制"功能，使用户能够通过在投屏画布上手动点击目标位置，记录点击坐标并持久化存储，形成可复用的点击模板库。录制的模板可供 AI 智能操控模块优先匹配使用，也可在添加脚本步骤时直接选择。

### 1.2 功能范围
- **点击事件录制**：在投屏区域激活录制模式 → 点击目标位置 → 弹出表单保存点击坐标
- **录制模板管理**：分页列表查看、行内编辑名称、删除记录
- **模板复用**：供 AI 助手和步骤添加对话框调用

### 1.3 服务定位
- **数据存储**：独立的 `recorded_clicks` 表，与脚本步骤表解耦
- **运行环境**：Electron 主进程（TypeORM + SQLite）+ 渲染进程（React 组件）

## 4. 数据模型

### 4.1 实体定义

表名：`recorded_clicks`

| 字段 | TypeORM 类型 | SQL 类型 | 约束 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| `id` | `@PrimaryGeneratedColumn()` | INTEGER | PK, AUTOINCREMENT | 自增主键 |
| `name` | `@Column('text')` | TEXT | NOT NULL | 用户自定义名称，如"点击微信" |
| `x` | `@Column('integer')` | INTEGER | NOT NULL | 设备物理坐标 X |
| `y` | `@Column('integer')` | INTEGER | NOT NULL | 设备物理坐标 Y |
| `type` | `@Column('text', { default: 'click' })` | TEXT | NOT NULL, DEFAULT 'click' | 动作类型，当前固定为 click |
| `ext` | `@Column('text', { nullable: true })` | TEXT | NULLABLE | 扩展字段，JSON 格式，预留后续扩展 |
| `ext` | `@Column('text', { nullable: true })` | TEXT | NULLABLE | 扩展字段，JSON 格式，预留后续扩展（如 swipe 方向、长按时长等） |
| `created_at` | `@CreateDateColumn()` | DATETIME | NOT NULL | 创建时间 |
| `updated_at` | `@UpdateDateColumn()` | DATETIME | NOT NULL | 更新时间 |

### 4.2 数据库 DDL

```sql
CREATE TABLE IF NOT EXISTS "recorded_clicks" (
    "id" INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
    "name" text NOT NULL,
    "x" integer NOT NULL,
    "y" integer NOT NULL,
    "type" text NOT NULL DEFAULT 'click',
    "ext" text,
    "created_at" datetime NOT NULL DEFAULT (datetime('now')),
    "updated_at" datetime NOT NULL DEFAULT (datetime('now'))
)
```

### 4.3 与 scripts/steps 表的关系

`recorded_clicks` 是独立表，与 `scripts`、`steps` 无外键关联。录制的点击模板作为跨功能的公用数据源，供以下模块调用：

- **AI 智能操控模块**：在意图理解节点中，优先查询 `recorded_clicks` 表中名称匹配的模板，直接使用其坐标执行
- **步骤管理模块**：在 `NewStepDialog` 中增加"从录制模板选择"入口，选中后自动填充步骤参数

## 5. 模块详细设计

### 5.1 Repository 层 — RecordedClickRepository

```
src/main/script/repositories/recorded-click-repository.ts
```

| 方法 | 参数 | 返回值 | 说明 |
| :--- | :--- | :--- | :--- |
| `create(params)` | `{ name: string, x: number, y: number, type: string }` | `RecordedClickEntity` | 创建录制记录 |
| `findAll(page, pageSize)` | `page: number, pageSize: number` | `{ items, total, page, pageSize, totalPages }` | 分页查询，按 created_at DESC 排序 |
| `findById(id)` | `id: number` | `RecordedClickEntity \| null` | 按主键查询 |
| `update(id, updates)` | `id: number, updates: { name?: string }` | `RecordedClickEntity \| null` | 更新名称等字段 |
| `delete(id)` | `id: number` | `boolean` | 删除记录 |
| `count()` | — | `number` | 查询总记录数 |

**分页实现**：
- 使用 `repository.findAndCount()` 或分别调用 `find()` + `count()`
- `skip = (page - 1) * pageSize`, `take = pageSize`
- `totalPages = Math.ceil(total / pageSize)`

### 5.2 Service 层 — RecordedClickService

```
src/main/script/services/recorded-click-service.ts
```

遵循 `ScriptService` 的模式：
- 构造函数中实例化 `RecordedClickRepository`
- `ensureInitialized()` 调用 `initializeDatabase()`（幂等）
- 所有 public 方法首先调用 `ensureInitialized()`，然后委托给 Repository

| 方法 | 说明 |
| :--- | :--- |
| `create(name, x, y, type)` | 校验参数后调用 repository.create |
| `getAll(page, pageSize)` | 调用 repository.findAll，默认 page=1, pageSize=10 |
| `update(id, updates)` | 调用 repository.update |
| `delete(id)` | 调用 repository.delete |

#### 5.3.2 IPC Handler（主进程）

在 `registerScriptHandlers()` 中注册：

| IPC 通道 | 参数 | 返回 | 说明 |
| :--- | :--- | :--- | :--- |
| `recordedClick:create` | `{ name, x, y, type }` | `{ success, data: entity }` | 创建录制记录 |
| `recordedClick:getAll` | `{ page, pageSize }` | `{ success, data: { items, total, page, pageSize, totalPages } }` | 分页查询 |

| `recordedClick:delete` | `id: number` | `{ success, data: boolean }` | 删除记录 |

所有 handler 遵循统一错误处理模式：
```typescript
try {
  // 业务逻辑
  return { success: true, data: result }
} catch (error) {
  return { success: false, error: String(error) }
}
```

#### 5.5.2 Canvas 位置追踪

使用 `ResizeObserver` 监听 `<canvas>` 元素和内容容器的尺寸变化，实时更新 `canvasRect`：

```typescript
useEffect(() => {
  const updateRect = () => {
    const canvas = document.querySelector('canvas')
    const content = contentRef.current
    if (!canvas || !content) return
    const cr = canvas.getBoundingClientRect()
    const nr = content.getBoundingClientRect()
    setCanvasRect({
      top: cr.top - nr.top,
      left: cr.left - nr.left,
      width: cr.width,
      height: cr.height,
    })
  }
  // ResizeObserver + window resize 事件
}, [isConnected, isMinimized])
```

#### 5.5.3 蒙版交互

| 场景 | 行为 |
| :--- | :--- |
| 录制模式激活 | 在 canvas 位置渲染半透明黑色蒙版（`bg-black/40`），鼠标变为 `cursor-crosshair` |
| 点击蒙版 | 阻止事件穿透，通过 `canvas.getBoundingClientRect()` 将页面坐标映射为设备物理坐标 |
| Escape 键 | `useEffect` 监听 `keydown` 事件，退出录制模式 |
| 蒙版范围 | 使用 `canvasRect` 精确定位，仅覆盖 canvas 区域（含 `rounded-lg` 圆角） |
| z-index | 蒙版 `z-30`，高于连接遮盖层 `z-10` 但低于浮动按钮 `z-40` |

**坐标映射公式**：

```
设备 X = (点击页面X - canvas左边界) × (设备宽度 / canvas CSS宽度)
设备 Y = (点击页面Y - canvas上边界) × (设备高度 / canvas CSS高度)
```

### 5.6 交互流程

#### 流程一：手动录制点击事件

```

  ↓
isRecording = true
  ↓
Canvas 上出现半透明蒙版 (cursor: crosshair)
底部状态栏显示 "录制模式"
  ↓
用户在蒙版上点击目标位置
  ↓
handleOverlayClick(e):
  1. 获取 canvas.getBoundingClientRect()
  2. 计算设备物理坐标 (x, y)
  3. setRecordCoord({ x, y })
  4. setShowFormDialog(true)
  ↓
RecordClickFormDialog 弹出
  ├─ 名称: [用户输入] (必填, placeholder: "例如：点击微信")
  ├─ 坐标 X: [自动填入, disabled]
  ├─ 坐标 Y: [自动填入, disabled]
  └─ 类型: [点击 卡片高亮, disabled]
  ↓
点击 "保存"
  ↓
电子API: recordedClick.create({ name, x, y, type: 'click' })
  ↓
主进程: RecordedClickService.create() → Repository.create() → SQLite INSERT
  ↓
保存成功 → onSaved() → setIsRecording(false) → 关闭弹窗 → 退出录制模式
```

#### 流程二：查看录制模板列表

```
用户点击查看按钮
  ↓
setShowListDialog(true)
  ↓
RecordedClickListDialog 打开
  ↓
useEffect → loadData(1)
  ↓
IPC: recordedClick.getAll({ page: 1, pageSize: 10 })
  ↓
列表展示（或加载中 / 空状态 / 错误状态）

#### 流程三：编辑 / 删除录制模板

```

  点击行右侧编辑按钮
  → 行内名称变为 Input + 保存/取消

删除:

  → ConfirmDialog 确认
  → 确认 → IPC: recordedClick.delete(id)

## 6. IPC 消息协议

### 6.1 Request / Response 格式

所有 IPC 请求统一返回格式：

```typescript
interface IpcResult<T = any> {
  success: boolean
  data?: T
  error?: string
}
```

### 6.2 接口定义

#### `recordedClick:create`

**Request**:
```typescript
{
  name: string    // 用户自定义名称
  x: number       // 设备物理坐标 X
  y: number       // 设备物理坐标 Y
  type: string    // 动作类型，固定 "click"
}
```

**Response**:
```typescript
{
  success: true,
  data: {
    id: number
    name: string
    x: number
    y: number
    type: string
    createdAt: string  // ISO 8601
    updatedAt: string  // ISO 8601
  }
}
```

#### `recordedClick:getAll`

**Request**:
```typescript
{
  page: number      // 页码，从 1 开始
  pageSize: number  // 每页条数，默认 10
}
```

**Response**:
```typescript
{
  success: true,
  data: {
    items: Array<{
      id: number
      name: string
      x: number
      y: number
      type: string
      createdAt: string
      updatedAt: string
    }>
    total: number       // 总记录数
    page: number        // 当前页码
    pageSize: number    // 每页条数
    totalPages: number  // 总页数
  }
}
```

#### `recordedClick:update`

**Request**:
```typescript
{
  id: number
  updates: {
    name?: string   // 可更新的字段
  }
}
```

**Response**:
```typescript
{
  success: true,
  data: { /* 更新后的完整实体 */ }
}
```

#### `recordedClick:delete`

**Request**:
```typescript
number  // id，直接传值
```

**Response**:
```typescript
{
  success: true,
  data: true  // boolean，是否删除成功
}
```

## 7. 边界情况与错误处理

### 7.1 前端错误场景

| 场景 | 处理方式 |
| :--- | :--- |
| 设备未连接时录制 | 允许录制（坐标映射需要 deviceWidth/deviceHeight，若无则使用默认值 1，可点击但坐标无效） |
| 蒙版点击时 canvas 不存在 | `document.querySelector('canvas')` 返回 null，不做任何操作 |
| 名称保存为空 | 前端校验，显示错误提示，阻止提交 |
| IPC 调用超时或失败 | 显示错误提示 + 重试按钮（列表页） |
| 列表加载失败 | 显示错误文字 + 重试按钮 |
| 列表数据为空 | 显示空状态引导文字 |
| 分页时删除最后一条 | 自动回退到上一页 |
| 编辑时快速连续点击 | 使用 loading 状态禁用按钮，防止重复提交 |

### 7.2 后端错误场景

| 场景 | 处理方式 |
| :--- | :--- |
| 数据库未初始化 | Service 层 `ensureInitialized()` 自动初始化 |
| 插入失败（字段超长等） | 捕获异常，返回 `{ success: false, error }` |
| 更新不存在的记录 | Repository.update 返回 null，handler 返回 `{ success: true, data: null }` |
| 删除不存在的记录 | Repository.delete 返回 false，handler 返回 `{ success: true, data: false }` |
| 参数类型错误（x 传字符串等） | Repository 层的 TypeORM 自动转换或 SQLite 宽松类型处理 |
