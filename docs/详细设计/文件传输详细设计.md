## 1. 模块概述

### 1.1 模块定位

文件传输是 AutoClick 的辅助功能扩展，通过 ADB 协议在电脑与手机之间进行文件的双向传输。用户可以在侧栏「文件」Tab 中浏览手机端的文件目录，上传电脑文件到手机，或将手机文件下载到电脑本地。

### 1.2 职责边界

| **职责** | **说明** |
| :--- | :--- |
| **手机文件浏览** | 通过 ADB shell 命令列出手机端目录内容，支持点击进入子目录 |
| **文件上传** | 从电脑端选取文件，通过 ADB push 上传到手机当前目录 |
| **文件下载** | 选中手机端文件，通过 ADB pull 下载到电脑本地下载目录 |
| **目录导航** | 支持进入子目录、返回上级目录、显示面包屑导航 |
| **路径显示** | 显示当前所在手机路径，支持根目录（`/sdcard`）起始 |

| **不包含的职责** | **说明** |
| :--- | :--- |
| 文件编辑 | 不支持在电脑端编辑手机文件 |
| 批量传输进度 | 单文件传输，不涉及多文件并发或队列 |
| 文件搜索 | 不支持在手机端搜索文件 |
| 文件删除/重命名 | 当前版本仅支持浏览和传输，不支持手机端文件管理操作 |

### 1.3 架构决策

| **决策项** | **选择** | **原因** |
| :--- | :--- | :--- |
| 传输协议 | ADB push/pull（命令行） | 项目已用 ADB 作为设备通信协议，无需额外依赖 |
| 文件浏览 | `adb shell ls -l` 解析（支持 toybox/GNU 双格式） | 轻量级，无需安装额外服务 |
| 文件对话框 | Electron `dialog.showOpenDialog`（上传时） | 原生文件选择，体验一致 |
| 初始目录 | `/sdcard`，可通过 `..` 回到根 `/` 浏览完整文件系统 | Android 设备通用可读写目录 |
| 目录结构缓存 | 每次进入目录时实时拉取 | 保持与手机端文件系统同步，避免缓存不一致 |
| 缩略图生成 | `adb exec-out cat` + `sharp` 缩放 120px | 图片文件懒加载缩略图预览 |
| 上传后媒体扫描 | `adb shell am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE` | 上传的照片在图库中立即可见 |

## 2. IPC 通信设计

### 2.1 IPC 通道常量

```typescript
const FILE_TRANSFER = {
  LIST_DIR: 'file-transfer:listDir',
  UPLOAD: 'file-transfer:upload',
  DOWNLOAD: 'file-transfer:download',
  GET_THUMBNAIL: 'file-transfer:getThumbnail',
} as const
```

### 2.2 IPC 接口定义

| 通道 | 方向 | 参数 | 返回 |
| :--- | :--- | :--- | :--- |
| `file-transfer:listDir` | renderer → main | `{ path: string }` | `{ success: boolean, entries: FileEntry[], error?: string }` |
| `file-transfer:upload` | renderer → main | `{ localPath: string, remoteDir: string }` | `{ success: boolean, fileName: string, error?: string }` |
| `file-transfer:download` | renderer → main | `{ remotePath: string, localDir: string }` | `{ success: boolean, fileName: string, savePath: string, error?: string }` |
| `file-transfer:getThumbnail` | renderer → main | `{ path: string }` | `{ success: boolean, data: string \| null, error?: string }` |

### 2.3 Preload API

```typescript
const fileTransferAPI = {
  listDir: (path: string) =>
    ipcRenderer.invoke(FILE_TRANSFER.LIST_DIR, { path }),
  upload: (localPath: string, remoteDir: string) =>
    ipcRenderer.invoke(FILE_TRANSFER.UPLOAD, { localPath, remoteDir }),
  download: (remotePath: string, localDir: string) =>
    ipcRenderer.invoke(FILE_TRANSFER.DOWNLOAD, { remotePath, localDir }),
  getThumbnail: (path: string) =>
    ipcRenderer.invoke(FILE_TRANSFER.GET_THUMBNAIL, { path }),
}
```

## 3. 数据模型

### 3.1 文件条目类型

```typescript
interface FileEntry {
  name: string           // 文件名/目录名
  path: string           // 完整路径
  isDirectory: boolean   // 是否为目录
  size: number           // 文件大小（字节），目录时为 0
  modifiedTime: string   // 修改时间
  permissions: string    // 权限字符串，如 "drwxrwx--x"
}

interface FileInfo {
  name: string
  path: string
  isDirectory: boolean
  size: number
  modifiedTime: string
}
```

### 3.2 状态管理（Zustand Store）

```typescript
interface FileTransferStore {
  // 状态
  currentPath: string                // 当前浏览的手机路径
  entries: FileEntry[]               // 当前目录的文件列表
  selectedFile: FileEntry | null     // 当前选中的文件/目录
  loading: boolean                   // 加载中
  uploading: boolean                 // 上传中
  downloading: boolean               // 下载中
  error: string | null               // 错误信息
  breadcrumbs: string[]              // 面包屑路径分段

  // 操作
  navigateTo: (path: string) => Promise<void>
  navigateUp: () => Promise<void>
  navigateToBreadcrumb: (index: number) => Promise<void>
  selectFile: (entry: FileEntry | null) => void
  uploadFile: () => Promise<void>
  downloadFile: () => Promise<void>
  refresh: () => Promise<void>
}
```

## 4. 主进程实现设计

### 4.1 模块文件结构

```
src/main/file-transfer/
├── index.ts              # 模块入口 + IPC 处理器注册
├── adb-file-service.ts   # ADB 文件操作封装
└── types.ts              # 类型定义
```

### 4.2 ADB 命令实现

#### 目录列表（listDir）

```
adb shell ls -l {path}           # 获取目录列表
adb shell stat -c '%Y' {path}    # 获取文件修改时间戳
```

**解析逻辑**：
1. 执行 `adb shell ls -l /sdcard/` 获取 `ls -l` 格式输出
2. 通过检测日期字段格式区分 **toybox**（Android 默认，`YYYY-MM-DD HH:MM` 8列）与 **GNU**（`MMM DD HH:MM` 9+列）
3. 逐行解析：权限、链接数、所有者、组、大小、日期、时间、文件名
4. 过滤掉 `.` 和 `..` 条目
5. 排序：目录在前，文件在后，各自按**修改时间倒序**（最新文件在最上面）
6. 对每个条目补全完整路径

#### 上传文件（upload）

```
adb push {localPath} {remoteDir}/
```

**流程**：
1. 主进程接收渲染进程请求（含本地路径和远程目录）
2. 调用 `adb push` 命令推送文件
3. 解析命令输出，判断成功或失败
4. 返回结果给渲染进程

#### 下载文件（download）

```
adb pull {remotePath} {localDir}/
```

**流程**：
1. 用户选中手机端文件后点击下载
2. 主进程使用 Electron 的 `app.getPath('downloads')` 获取系统下载目录
3. 调用 `adb pull` 命令拉取文件到下载目录
4. 如果下载目录已存在同名文件，自动添加时间戳后缀（如 `file(20260702_153000).txt`）
5. 返回结果给渲染进程

#### 缩略图生成（getThumbnail）

```
adb exec-out cat {remotePath}  →  读取二进制图片数据
  → sharp 缩放至 120px cover  →  data:image/png;base64,...
```

**限制**：
- 仅支持 `.jpg/.jpeg/.png/.gif/.webp/.bmp` 格式
- 文件 > 5MB 跳过缩略图生成
- 前端通过 IntersectionObserver 懒加载，只对可见项触发
- 缩略图缓存于 `thumbnailCache` Map，切换目录自动清空

#### 上传后媒体扫描

上传完成后自动触发 MediaStore 扫描，使文件在图库中立即可见：

```
adb shell am broadcast -a android.intent.action.MEDIA_SCANNER_SCAN_FILE \
  -d file://{remotePath}
```

扫描失败不影响上传结果，静默忽略。

### 4.3 根目录策略

- 默认根目录：`/sdcard`
- 首次打开文件 Tab 时自动导航到 `/sdcard`
- 可通过 `..` 返回根目录 `/` 浏览完整文件系统
- 根目录 `/` 显示"内部存储"快速入口，一键跳回 `/sdcard`

### 5.3 交互流程

#### 流程一：浏览手机文件

```
用户切换到「文件」Tab
  → FileTransferPanel 挂载
  → fileTransferStore.navigateTo('/sdcard')
  → 主进程 adb shell ls -l /sdcard
  → 返回 FileEntry[] → 渲染列表
  → 用户点击目录项 → navigateTo(path) → 刷新列表
  → 用户点击面包屑某段 → navigateToBreadcrumb(index) → 跳转
  → 用户点击「..」→ navigateUp() → 返回上级
```

#### 流程二：上传文件（电脑 → 手机）

```
用户点击「📤 上传文件」按钮
  → 主进程弹出 dialog.showOpenDialog（文件选择）
  → 用户选择文件后确认
  → fileTransferStore.uploadFile()
  → 主进程 adb push localPath remoteDir/
  → 上传过程中显示 loading 状态
  → 上传完成 → 刷新当前目录列表
  → 显示成功 Toast 通知
  → 上传失败 → 显示错误 Toast 通知
```

#### 流程三：下载文件（手机 → 电脑）

```
用户在文件列表中点击选中一个文件（高亮）
  → 「📥 下载选中」按钮变为可用
  → 用户点击「📥 下载选中」
  → fileTransferStore.downloadFile()
  → 主进程获取 system download 目录
  → 主进程 adb pull remotePath localDir/
  → 下载过程中显示 loading 状态
  → 下载完成 → 显示成功 Toast 通知（含保存路径）
  → 下载失败 → 显示错误 Toast 通知
```

## 7. 状态管理设计

### 7.1 fileTransferStore 完整定义

```typescript
import { create } from 'zustand'

interface FileEntry {
  name: string
  path: string
  isDirectory: boolean
  size: number
  modifiedTime: string
  permissions: string
}

interface FileTransferStore {
  // 状态
  currentPath: string
  entries: FileEntry[]
  selectedFile: FileEntry | null
  breadcrumbs: string[]
  loading: boolean
  uploading: boolean
  downloading: boolean
  error: string | null
  thumbnailCache: Map<string, string | null>

  // 操作
  navigateTo: (path: string) => Promise<void>
  navigateUp: () => Promise<void>
  navigateToBreadcrumb: (index: number) => Promise<void>
  selectFile: (entry: FileEntry | null) => void
  uploadFile: () => Promise<void>
  downloadFile: () => Promise<void>
  refresh: () => Promise<void>
  getThumbnail: (path: string) => Promise<string | null>
}
```

### 7.2 store 实现要点

- `navigateTo`：设置 `loading=true` → 清空 `thumbnailCache` → 调用 `electronAPI.fileTransfer.listDir(path)` → 更新 `entries` 和 `breadcrumbs` → 重置 `selectedFile=null` → 设置 `loading=false`
- `navigateUp`：从 `currentPath` 中提取父目录路径，调用 `navigateTo`（根目录 `/` 时返回）
- `navigateToBreadcrumb`：根据面包屑索引构建路径，调用 `navigateTo`
- `selectFile`：仅当点击的是文件时设置 `selectedFile`，点击目录时触发导航
- `uploadFile`：弹出系统文件对话框 → `adb push` → 自动触发 MediaStore 扫描 → 刷新目录
- `downloadFile`：使用系统下载目录 + `adb pull`（重名自动加时间戳），完成后 Toast 通知
- `refresh`：重新加载当前目录
- `getThumbnail`：优先查 `thumbnailCache` → 未命中则调用 IPC → 缓存结果 → 返回 data URL

## 8. 错误处理

| 错误场景 | 处理方式 | 用户提示 |
| :--- | :--- | :--- |
| 设备未连接 | 检查 deviceStore.status，若未连接则提示 | "请先连接设备" |
| ADB 命令执行失败 | 捕获错误，返回错误信息 | "读取目录失败：{错误详情}" |
| 上传文件不存在 | 文件对话框后检查文件存在性 | "文件不存在" |
| 手机目录不存在 | 执行 ls 前检查 | "目录不存在" |
| 下载路径不可写 | 检查本地目录权限 | "无法写入下载目录" |
| 文件重名 | 自动添加时间戳后缀 | 无需提示，自动处理 |
| 权限不足（手机端） | 捕获 adb 权限错误 | "权限不足，请检查手机授权" |
| 缩略图读取失败 | 捕获错误并返回 null | 前端回退显示默认图标 |
| 大文件缩略图跳过 | 文件 > 5MB 时跳过 | 显示默认图标，无错误提示 |
| 上传后媒体扫描失败 | 静默忽略 | 不影响上传结果 |

## 9. UI 组件规范
