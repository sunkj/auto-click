## 1. 概述

等待步骤（`wait`）是一种新的脚本步骤类型，允许用户在脚本执行过程中插入指定时长的延时等待。它不需要依赖任何 ADB 命令或设备状态，纯本地执行，适用于页面加载、动画播放、数据刷新等场景。

## 4. 执行引擎设计

### 4.1 执行流程

```
case 'wait':
  await this.executeWait(resolvedData)
  break
```

`executeWait` 方法的实现逻辑：

```typescript
/**
 * 执行等待步骤
 * 通过延迟指定时长来实现等待，支持中断取消
 */
private async executeWait(data: Record<string, any>): Promise<void> {
  const durationSec = Number(data.duration) || 0
  if (durationSec <= 0) {
    throw new ScriptEngineError(ErrorCode.STEP_TYPE_INVALID, '等待时长必须大于 0')
  }
  
  const durationMs = Math.round(durationSec * 1000)
  console.log(`[StepExecutor] ⏳ 等待 ${durationSec} 秒...`)
  
  await new Promise<void>((resolve, reject) => {
    const timer = setTimeout(() => {
      cleanup()
      resolve()
    }, durationMs)
    
    const cleanup = () => {
      clearTimeout(timer)
      // 移除中断监听（如果有）
    }
    
    // 如果 execution-queue 支持中断，这里监听取消信号
    // 例如：cancelToken?.onCancelled(() => { cleanup(); reject(new Error('已取消')) })
  })
  
  console.log(`[StepExecutor] ✔ 等待完成 (${durationSec} 秒)`)
}
```

### 4.2 中断支持

等待期间应当支持脚本手动中断。实现方式：

- **方案**：利用 `execution-context.ts` 中的 `cancel` 机制
- 如果执行队列有 cancelToken / AbortSignal，等待期间监听中断信号
- 收到中断信号时立即清理 setTimeout 并抛出错误，脚本执行引擎捕获后标记为"已取消"

当前执行队列 (`execution-queue.ts`) 已支持 `cancel()` 方法，等待步骤通过检查 `context.cancelled` 或 `AbortSignal` 实现中断响应。

### 4.3 边界情况处理

| 场景 | 行为 |
| :--- | :--- |
| duration = 0 或负数 | 抛错 `等待时长必须大于 0` |
| duration = 0.5 | 等待 500ms（支持小数秒） |
| duration = 9999 | 等待 9999 秒（约 2.7 小时），实际应用中应避免超长等待 |
| 脚本取消/中断 | 立即停止等待，标记步骤为"已取消" |
| 步骤重试 | 如果等待步骤配置了重试，重试时会重新执行等待（合理，因为等待是幂等的） |

## 5. UI 设计

### 5.1 StepPanel 步骤列表显示

在步骤列表中，等待步骤的显示格式为：

```
3 ⏳ 等待    5.0s
```

- **图标**：`Hourglass`（lucide-react）
- **中文标签**：`等待`
- **参数描述**：`N.Ns`（显示小数秒，如 `3.0s`、`0.5s`）
- **颜色**：`text-amber-500`（暖色，体现"等待"语义）

### 5.2 NewStepDialog 步骤类型选择

在步骤类型选择列表中新增 `wait` 条目：

| 类型 | 标签 | 图标 | 颜色 |
| :--- | :--- | :--- | :--- |
| wait | 等待 | Hourglass | text-amber-500 |

### 5.3 NewStepDialog 表单

选择 wait 类型后，表单显示以下字段：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| 步骤名称 | text | 否 | "" | 可选的步骤名称 |
| 等待时长 | number | 是 | 3 | 等待时长，单位：秒，支持小数 |
| 原因说明 | text | 否 | "" | 等待原因（如"等待页面加载"），显示在步骤列表中 |

表单校验：
- 等待时长必须 > 0
- 等待时长最大限制为 3600（1 小时），超出时提示用户

### 5.4 步骤编辑

等待步骤的编辑弹窗与新建表单一致，预填已保存的参数值。

case 'wait':

## 7. 导入导出兼容性

`wait` 步骤类型的导入导出格式：

```javascript
// AutoClick 脚本 - wait_demo
[
  {"type":"wait","data":{"duration":3,"description":"等待页面加载"}},
  {"type":"click","data":{"x":500,"y":800,"description":"点击登录"}},
  {"type":"wait","data":{"duration":2}}
]
```

旧版本导入时遇到 `wait` 类型不会报错（脚本引擎的 `default` 分支会抛 `不支持的步骤类型`），因此新版本导入旧文件不受影响。
